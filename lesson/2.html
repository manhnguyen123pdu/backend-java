CÂU LỆNH IF

1.2.1. Dạng 1: Câu lệnh if

Định nghĩa: Câu lệnh if dùng để kiểm tra một điều kiện, nếu điều kiện đúng (true) thì đoạn mã trong khối if sẽ được thực thi.

Cú pháp
if (<điều_kiện>) {
    <khối_lệnh>;
}

Lưu đồ thuật toán câu lệnh IF

Ví dụ: Kiểm tra 1 số chẵn lẻ

IfExample.java
public class IfExample {
    public static void main(String[] args) {
        int number = 5;
        
        if (number > 0) {
            System.out.println("Số dương");
        }
        
        System.out.println("Chương trình kết thúc");
    }
}

Giải thích chi tiết:

  • BƯỚC 1: Khai báo biến number = 5
  • BƯỚC 2: Kiểm tra điều kiện number > 0 → 5 > 0 → TRUE
  • BƯỚC 3: Thực thi khối lệnh trong if → in "Số dương"
  • BƯỚC 4: Tiếp tục chương trình → in "Chương trình kết thúc"

Kết quả:
Số dương
Chương trình kết thúc

CÂU LỆNH IF...ELSE

1.2.2. Dạng 2: Câu lệnh if...else

Định nghĩa: if...else là câu lệnh điều kiện có 2 nhánh: Nếu điều kiện đúng → chạy khối lệnh trong if, nếu sai → chạy khối lệnh trong else.

Cú pháp
if (<điều_kiện>) {
    <khối_lệnh1>;
} else {
    <khối_lệnh2>;
}

Lưu đồ thuật toán câu lệnh IF

IfElseExample.java
public class IfElseExample {
    public static void main(String[] args) {
        double score = 4.5;
        if (score >= 5) {
            System.out.println("Đậu");
        } else {
            System.out.println("Rớt");
        }
        System.out.println("Kết thúc kiểm tra");
    }
}

Giải thích chi tiết:

  • BƯỚC 1: Khai báo biến score = 4.5
  • BƯỚC 2: Kiểm tra điều kiện score >= 5 → 4.5 >= 5 → FALSE
  • BƯỚC 3: Nhảy đến khối else (vì điều kiện sai)
  • BƯỚC 4: Thực thi khối else → in "Rớt"
  • BƯỚC 5: Tiếp tục chương trình → in "Kết thúc kiểm tra"

Kết thúc kiểm tra

1.2.3. Dạng 3: Câu lệnh if...else if...else

Định nghĩa: Cho phép kiểm tra nhiều điều kiện khác nhau, theo thứ tự từ trên xuống. Khi gặp điều kiện đúng đầu tiên, chương trình sẽ thực hiện và không kiểm tra tiếp.

Cú pháp
if (<điều_kiện1>) {
    <khối_lệnh1>;
} else if (<điều_kiện2>) {
    <khối_lệnh2>;
} else if (<điều_kiện3>) {
    <khối_lệnh3>;
} else {
    <khối_lệnh4>;
}

Lưu đồ thuật toán câu lệnh IF

TOÁN TỬ BA NGÔI

1.3 Toán tử ba ngôi (Ternary Operator)

Định nghĩa: Là cú pháp rút gọn của if...else, dùng khi cần lựa chọn giữa hai giá trị.

Cú pháp
điều_kiện ? giá_trị_nếu_đúng : giá_trị_nếu_sai;

Ý nghĩa:

Giúp viết mã ngắn gọn và súc tích hơn, nhất là khi chỉ cần trả về một giá trị.

TernaryOperator.java
public class TernaryOperator {
    public static void main(String[] args) {
        double score = 6.0;
        
        // Sử dụng if-else thông thường
        String result1;
        if (score >= 5) {
            result1 = "Đậu";
        } else {
            result1 = "Rớt";
        }
        
        // Sử dụng toán tử ba ngôi
        String result2 = (score >= 5) ? "Đậu" : "Rớt";
        
        System.out.println("Kết quả (if-else): " + result1);
        System.out.println("Kết quả (ternary): " + result2);
        
        // Ví dụ phức tạp hơn
        int number = 10;
        String message = (number % 2 == 0) ? "Số chẵn" : "Số lẻ";
        System.out.println(number + " là " + message);
    }
}

CÂU LỆNH SWITCH-CASE

1.4 Câu lệnh switch...case

Định nghĩa: Câu lệnh switch dùng để so sánh một giá trị với nhiều trường hợp khác nhau (case).

Cú pháp
switch (biểu_thức) {
    case giá_trị_1:
        <khối_lệnh_1>;
        break;
    case giá_trị_2:
        <khối_lệnh_2>;
        break;
    ...
    case giá_trị_n:
        <khối_lệnh_n>;
        break;
    default:
        <khối_lệnh_mặc_định>;
}

Lưu đồ thuật toán câu lệnh IF

SwitchExample.java
public class SwitchExample {
    public static void main(String[] args) {
        int dayOfWeek = 3;
        String dayName;
        
        switch (dayOfWeek) {
            case 1:
                dayName = "Chủ Nhật";
                break;
            case 2:
                dayName = "Thứ Hai";
                break;
            case 3:
                dayName = "Thứ Ba";
                break;
            case 4:
                dayName = "Thứ Tư";
                break;
            case 5:
                dayName = "Thứ Năm";
                break;
            case 6:
                dayName = "Thứ Sáu";
                break;
            case 7:
                dayName = "Thứ Bảy";
                break;
            default:
                dayName = "Không hợp lệ";
        }
        
        System.out.println("Ngày " + dayOfWeek + " là: " + dayName);
    }
}

Giải thích chi tiết:

  • BƯỚC 1: dayOfWeek = 3
  • BƯỚC 2: So sánh với case 1 → không khớp
  • BƯỚC 3: So sánh với case 2 → không khớp
  • BƯỚC 4: So sánh với case 3 → KHỚP
  • BƯỚC 5: Thực thi dayName = "Thứ Ba"
  • BƯỚC 6: Gặp break → thoát switch
  • BƯỚC 7: In kết quả

Kết quả:
Ngày 3 là: Thứ Ba

TOÁN TỬ LOGIC

1.5 Toán tử logic &&, ||, !

Định nghĩa:

  • && (AND): Đúng khi cả hai điều kiện đúng
  • || (OR): Đúng khi ít nhất một điều kiện đúng
  • ! (NOT): Phủ định điều kiện (đúng thành sai và ngược lại)
Nội dung AND (&&) OR (||)
Lưu đồ
Mô tả Chỉ trả về TRUE khi cả hai điều kiện đều đúng Trả về TRUE khi ít nhất một điều kiện đúng
Short-circuit Evaluation Nếu điều kiện đầu tiên sai → kết thúc ngay Nếu điều kiện đầu tiên đúng → kết thúc ngay

Ý nghĩa:

Toán tử && và || thực hiện đánh giá từ trái sang phải và có cơ chế "short-circuit" (ngắt mạch), nghĩa là dừng kiểm tra ngay khi có kết quả xác định.

LogicalOperators.java
public class LogicalOperators {
    public static void main(String[] args) {
        int age = 20;
        boolean hasID = true;
        
        // Sử dụng AND (&&)
        if (age >= 18 && hasID) {
            System.out.println("Được vào cửa");
        } else {
            System.out.println("Không được vào");
        }
        
        // Sử dụng OR (||)
        boolean isWeekend = true;
        boolean isHoliday = false;
        
        if (isWeekend || isHoliday) {
            System.out.println("Hôm nay được nghỉ");
        } else {
            System.out.println("Hôm nay đi làm");
        }
        
        // Sử dụng NOT (!)
        boolean isRaining = false;
        
        if (!isRaining) {
            System.out.println("Trời không mưa, có thể đi chơi");
        } else {
            System.out.println("Trời mưa, ở nhà");
        }
    }
}

MẸO VÀ THỦ THUẬT

1.6 Mẹo và cú pháp viết nhanh

Kỹ thuật Mô tả Ví dụ
if (a) Kiểm tra nếu a tồn tại (truthy) if (name != null)
if (!a) Kiểm tra nếu a không tồn tại (falsy) if (!isEmpty)
Viết gọn if đơn Bỏ {} nếu chỉ có 1 lệnh if (condition) statement;
Toán tử so sánh So sánh chuỗi dùng equals() if (str.equals("hello"))
QuickSyntax.java
public class QuickSyntax {
    public static void main(String[] args) {
        String name = "John";
        boolean isEmpty = false;
        
        // Kiểm tra null và rỗng
        if (name != null && !name.isEmpty()) {
            System.out.println("Tên hợp lệ: " + name);
        }
        
        // Viết gọn if đơn
        int x = 10;
        if (x > 5) System.out.println("x lớn hơn 5");
        
        // So sánh chuỗi
        String input = "hello";
        if (input.equals("hello")) {
            System.out.println("Chào mừng!");
        }
    }
}

Best Practices:

  • Luôn sử dụng {} cho khối lệnh, kể cả khi chỉ có 1 dòng
  • Sử dụng equals() để so sánh chuỗi, không dùng ==
  • Kiểm tra null trước khi gọi phương thức trên đối tượng
  • Sử dụng toán tử ba ngôi cho các trường hợp đơn giản

VÒNG LẶP FOR

2.2 Vòng lặp for

Định nghĩa: Vòng lặp for được sử dụng khi biết trước số lần lặp.

Lưu đồ thuật toán:

Cú pháp
for (khởi_tạo; điều_kiện; cập_nhật) {
    // Khối lệnh thực thi
}

Giải thích các thành phần:

  • khởi_tạo: Khai báo và khởi tạo biến đếm (chạy 1 lần duy nhất)
  • điều_kiện: Kiểm tra trước mỗi lần lặp, nếu true thì tiếp tục
  • cập_nhật: Thay đổi biến đếm sau mỗi lần lặp
  • khối lệnh: Các câu lệnh được thực thi trong mỗi vòng lặp
ForLoopBasic.java
public class ForLoopBasic {
    public static void main(String[] args) {
        System.out.println("=== VÒNG LẶP FOR CƠ BẢN ===");
        
        for (int i = 1; i <= 5; i++) {
            System.out.println("Lần lặp thứ: " + i);
        }
        System.out.println("Kết thúc vòng lặp");
    }
}

Giải thích chi tiết luồng thực thi:

  • BƯỚC 1: Khởi tạo - int i = 1 (chạy 1 lần)
  • BƯỚC 2: Kiểm tra điều kiện - i <= 5 → 1 <= 5 → TRUE
  • BƯỚC 3: Thực thi khối lệnh - in "Lần lặp thứ: 1"
  • BƯỚC 4: Cập nhật - i++ → i = 2
  • BƯỚC 5: Kiểm tra điều kiện - i <= 5 → 2 <= 5 → TRUE
  • BƯỚC 6: Thực thi khối lệnh - in "Lần lặp thứ: 2"
  • BƯỚC 7: Cập nhật - i++ → i = 3
  • BƯỚC n: Khi i = 6 → điều kiện 6 <= 5 → FALSE → thoát vòng lặp

Kết quả:

VÒNG LẶP WHILE

2.3 Vòng lặp while

Định nghĩa: Vòng lặp while được sử dụng khi không biết trước số lần lặp, kiểm tra điều kiện trước khi thực thi.

Lưu đồ thuật toán:

Cú pháp
while (điều_kiện) {
    // Khối lệnh thực thi
    // Cập nhật biến điều kiện
}

Ví dụ 1: Đếm ngược từ 10 đến 1

WhileLoopBasic.java
public class WhileLoopBasic {
    public static void main(String[] args) {
        System.out.println("=== VÒNG LẶP WHILE - ĐẾM NGƯỢC ===");
        int count = 10;
        
        while (count > 0) {
            System.out.println("Đếm: " + count);
            count--;
            // Giảm count đi 1, quan trọng: phải cập nhật biến điều kiện
        }
        System.out.println("Chúc mừng năm mới!");
    }
}

Giải thích chi tiết luồng thực thi:

  • BƯỚC 1: Khởi tạo count = 10
  • BƯỚC 2: Kiểm tra count > 0 → 10 > 0 → TRUE
  • BƯỚC 3: Thực thi - in "Đếm: 10"
  • BƯỚC 4: Cập nhật - count-- → count = 9
  • BƯỚC 5: Kiểm tra count > 0 → 9 > 0 → TRUE
  • BƯỚC 6: Thực thi - in "Đếm: 9"
  • BƯỚC n: Khi count = 0 → điều kiện 0 > 0 → FALSE → thoát vòng lặp

Kết quả:
=== VÒNG LẶP WHILE - ĐẾM NGƯỢC ===

Đếm: 9
Đếm: 8
.....
Đếm: 1

VÒNG LẶP DO-WHILE

2.4 Vòng lặp do-while

Định nghĩa: Vòng lặp do-while thực thi khối lệnh ít nhất 1 lần, sau đó mới kiểm tra điều kiện.

Lưu đồ thuật toán:

Cú pháp
do {
    // Khối lệnh thực thi (ít nhất 1 lần)
    // Cập nhật biến điều kiện
} while (điều_kiện);

Ví dụ: Menu lựa chọn

DoWhileMenu.java
import java.util.Scanner;

public class DoWhileMenu {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int choice;
        
        System.out.println("=== HỆ THỐNG QUẢN LÝ SINH VIÊN ===");
        
        do {
            // Hiển thị menu
            System.out.println("\n===== MENU CHÍNH =====");
            System.out.println("1. Xem danh sách sinh viên");
            System.out.println("2. Thêm sinh viên mới");
            System.out.println("3. Sửa thông tin sinh viên");
            System.out.println("4. Xóa sinh viên");
            System.out.println("5. Thoát chương trình");
            System.out.print("Chọn chức năng (1-5): ");
            
            choice = scanner.nextInt();
            
            // Xử lý lựa chọn
            switch (choice) {
                case 1:
                    System.out.println("Đang hiển thị DS sinh viên...");
                    break;
                case 2:
                    System.out.println("Đang thêm sinh viên mới...");
                    break;
                case 3:
                    System.out.println("Đang sửa thông tin SV...");
                    break;
                case 4:
                    System.out.println("Đang xóa sinh viên...");
                    break;
                case 5:
                    System.out.println("Cảm ơn đã sử dụng! Tạm biệt!");
                    break;
                default:
                    System.out.println("Lựa chọn không hợp lệ!");
            }
            
        } while (choice != 5); // Lặp lại cho đến khi chọn 5 (Thoát)
        scanner.close();
    }
}

Giải thích chi tiết:

  • BƯỚC 1: Hiển thị menu và nhập lựa chọn (luôn chạy ít nhất 1 lần)

public class Factorial {

public class PrimeNumber {
    public static void main(String[] args) {
        int number = 17;
        boolean isPrime = true;
        
        if (number <= 1) {
            isPrime = false;
        } else {
            for (int i = 2; i <= Math.sqrt(number); i++) {
                if (number % i == 0) {
                    isPrime = false;
                    break;
                }
            }
        }
        
        if (isPrime) {
            System.out.println(number + " là số nguyên tố");
        } else {
            System.out.println(number + " không phải số nguyên tố");
        }
    }
}

2.7 break và continue trong Java

2.7.1 Từ khóa break trong Java

Mục đích: Dùng để thoát khỏi vòng lặp hoặc câu lệnh switch ngay lập tức, trước khi nó kết thúc tự nhiên. Khi gặp break, chương trình sẽ dừng vòng lặp hiện tại và chuyển sang thực hiện lệnh tiếp theo sau vòng lặp.

Lưu đồ thuật toán:

Ví dụ : Thoát vòng lặp khi tìm thấy số chia hết cho 7

BreakExample.java
public class BreakExample {
    public static void main(String[] args) {
        for (int i = 1; i <= 10; i++) {
            if (i % 7 == 0) {
                System.out.println("So chia het cho 7: " + i);
                break; // Thoát khỏi vòng lặp
            }
            System.out.println("Dang kiem tra i = " + i);
        }
        System.out.println("Ket thuc vong lap!");
    }
}

2.7.2 Từ khóa continue trong Java

Mục đích: Dùng để bỏ qua phần còn lại của vòng lặp hiện tại và chuyển sang lần lặp tiếp theo.

Lưu đồ thuật toán:

Ví dụ : Bỏ qua số chẵn trong vòng lặp

ContinueExample.java
public class ContinueExample {
    public static void main(String[] args) {
        for (int i = 1; i <= 10; i++) {
            if (i % 2 == 0) {
                continue; // Bỏ qua các số chẵn
            }
            System.out.println("So le: " + i);
        }
    }
}

Ví dụ tổng hợp break và continue

BreakContinueDemo.java
public class BreakContinueDemo {
    public static void main(String[] args) {
        for (int i = 1; i <= 10; i++) {
            if (i == 3) {
                continue; // Bỏ qua i = 3
            }
            
            if (i == 8) {
                break; // Thoát vòng lặp khi i = 8
            }
            
            System.out.println("i = " + i);
        }
        System.out.println("Ket thuc chuong trinh");
    }
}
